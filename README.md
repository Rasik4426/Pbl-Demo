# PBL-inspired demo

Open `index.html` in a modern browser. The project is organized into separate HTML, CSS, and JavaScript files.

The local School of Computing and School of Engineering pages follow the reference pages’ school-specific layout, icons, sections, and interactions. Navigation and school switching stay local; Computing includes the management table, resource downloads, and leadership carousel with clickable/keyboard flip cards. The School of Computing Student Login opens a local awareness-demo page styled from the supplied reference. It is clearly marked unofficial, does not authenticate anyone, never reads or displays field values, and clears the form on submit; no credentials are saved or sent. Faculty pages remain blank placeholders.

The home page retains its hover, card-flip, and keyboard interactions. Some logos, portraits, and hero artwork load from public image assets, while recognition graphics are included locally. This is an unofficial design demo and is not affiliated with MIT-ADT University.

The School of Engineering Student Login uses the supplied PBLSOES page design and graphics. The original uploaded HTML, CSS, JavaScript, and assets are preserved under soe/login-source/. The integrated page uses a separate local script: password visibility and page navigation work, while submit only clears the form and shows a local-demo notice; it never reads, stores, or sends the form values. soe/student.html is the Engineering student route.
